# 黎安话事

微信小程序：学习分享 + 互助广场。品牌名「黎安话事」。

启动时会先进入封面页 `pages/splash/splash`，约 1.6 秒后自动进入学习分享。

上线架构：**用户端小程序 + 独立 Web 后台 + 微信云开发数据库**。学生只看到小程序；运营在电脑浏览器打开后台。

## 两端如何分开

| | 用户端小程序 | 独立后台 |
| --- | --- | --- |
| 入口 | 微信内打开，底部 Tab：学习分享 / 互助广场 / 我的 | 浏览器访问 `admin` 服务，需登录 |
| 界面 | 暖色社区风格 | 深蓝控制台 |
| 能力 | 浏览、发帖、评论、学校认证 | 内容审帖、词库启停、账号处置、汇总推送、客户群、学校/学生认证 |
| 数据 | 云函数读写云库 | 云开发 Node SDK 读写同一云库 |
| 互相可见 | 无管理入口 | 不进入学生小程序 |

本地未配置云环境时，小程序仍可用本机 Storage 演示。上线必须打开云数据库，否则各手机数据不通。

## 上线步骤

1. 微信开发者工具开通 **云开发**，记下环境 ID  
2. 在云开发控制台创建集合（见 `cloud/collections.json`），权限全部设为 **客户端不可读写**  
3. 上传并部署云函数 `login`、`userApi`  
4. 填写 `utils/config.js` 里的 `cloudEnvId`  
5. 复制 `admin/.env.example` 为 `admin/.env`，填入环境 ID 和腾讯云 API 密钥  
6. 启动独立后台：

```bash
cd admin
npm install
npm start
```

浏览器打开 `http://127.0.0.1:8787`，用 `.env` 里的管理员账号登录。

**本地演示（不配云库）**：`admin/.env` 设 `ADMIN_LOCAL=1`（或不填 TCB 三项），默认账号 `admin / admin123`。后台会用 `admin/data/local-store.json` 预置待审帖、词库，可直接练审帖 / 词库 / 账号处置。

**正式云库**：填齐 `TCB_ENV / TCB_SECRET_ID / TCB_SECRET_KEY`，并去掉 `ADMIN_LOCAL`；云库需有 `lexicon_terms` 集合。

**运营自动化接库**：小程序端不能直连数据库；脚本与后台一样用腾讯云 API 密钥 + Node SDK。见 [`ops/README.md`](ops/README.md)（`npm run ping` / `npm run stats`）。

演示/本地后台账号不要再用小程序里的 `admin888`。密码只放服务器环境变量。

## 用户端功能

- **学习分享**：校园生活、学习交流、吐槽树洞、活动组队
- **互助广场**：二手闲置流转、出行拼车、拼单互助、求物求助、失物招领；仅指定频道可填微信号，不进正文，认证同学点按钮后可复制
- **我的**：头像昵称、学校认证、发布/获赞统计、我的帖子/点赞
- **门槛**：所有人可浏览；发帖/评论/查看联系方式需先认证学校；学校可手填或从常用列表点选，提交后不可修改
- **学校标签**：个人主页默认不展示学校；用户可开启「展示学校标签」，此后主页与发帖头像旁显示认证学校
- **学生认证**：可上传学生证/在读证明，管理员人工审核；材料仅用于核验，不对外展示；主页展示认证状态
- **一期风控**：先标准化文本，再跑本地信号词库与组合规则；短词/缩写/「私我」不能单独拒绝。云审核接口一期预留，超时不默认放行
- **审核**：发帖先不可见；按「紧急拦截＞拒绝＞人工＞要求修改＞通过」合并结果。后台可审帖，并可增删启停词库、记版本
- **联系方式**：仅拼车、二手闲置、失物招领可填专用微信号字段并点按钮查看；正文出现微信号/手机号/QQ/二维码会要求修改
- **互助广场排序**：用户端支持「最热 / 最新」
- **每周精选热榜**：独立板块，管理员上架/排序/开关，类似热榜；与群发汇总推送互不影响
- **分发**：只推校园墙，不推论坛。满 10 条自动走企微客户群群发，群主确认一次后同学可见

## 如何本地跑用户端

1. 安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 选择「导入项目」，目录指向本文件夹
3. `utils/config.js` 的 `cloudEnvId` 留空，即用本地 Storage
4. 编译预览

## 目录

```text
app.js / app.json / app.wxss
pages/                 用户端
cloudfunctions/        云函数 login / userApi
cloud/                 集合说明
admin/                 独立运营后台
utils/
  config.js       云环境开关
  repo.js         本地 / 云端数据门面
  store.js        本地演示数据层
server/wecom-distribute.js
```

`packageAdmin/` 是旧的小程序内管理端，已从 `app.json` 移除，上线不要再用。

## 企微自动群发（必须）

目标群：群主企微 + 同学普通微信，例如「群聊推送测试」。

开发者可以不在这家公司。流程是：

1. 公司里能进企微后台的人，把 **企业ID、应用 Secret、群主账号（马飘）** 发给开发者  
2. 开发者填进 `server/.env`，并在云开发控制台给云函数 `userApi` 配同样的环境变量  
3. 后台「客户群」点 **拉取并绑定「群聊推送测试」**，或运行 `node server/list-groups.js`  
4. 校园墙满 10 条 → 云函数自动创建企微群发  
5. 群主在自己的企业微信点一次「确认发送」  
6. 同学在群里点小程序卡片 → 汇总页 → 详情

本地可先跑 `node server/send-to-group.js` 做一次试发。
